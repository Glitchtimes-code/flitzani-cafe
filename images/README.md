# Φωτογραφίες

Αρχεία που περιμένει το site (σε μορφή WebP, συμπιεσμένα):

| Αρχείο | Χρήση | Προτεινόμενο μέγεθος |
|---|---|---|
| `hero.webp` | Φόντο του hero | 1600 × 1000 px, κάτω από ~200 KB |
| `interior.webp` | Ενότητα «Η ιστορία μας» | 1000 × 1000 px, κάτω από ~150 KB |
| `sweets.webp` | Πανοραμικό banner στο μενού | 1600 × 700 px, κάτω από ~150 KB |

Αν ένα αρχείο λείπει, το site δείχνει ένα διακριτικό gradient στη θέση του.

Τα ονόματα πρέπει να είναι ακριβώς αυτά (πεζά, χωρίς κενά).
